# Playwright TypeScript E-Commerce Automation Framework

A hands-on UI automation project built with Playwright and TypeScript to test the SauceDemo e-commerce application.

## 🚀 Project Highlights

- **Automation:** Playwright with TypeScript
- **Browsers:** Chromium, Firefox, and WebKit
- **Test scenarios:** Login, products, shopping cart, and checkout
- **Reporting:** Playwright HTML Report and Allure Report
- **CI/CD:** GitHub Actions
- **Debugging:** Screenshots, traces, and videos for failed tests
- **Report hosting:** GitHub Pages

## 🧰 Tech Stack

Playwright · TypeScript · Node.js · Git · GitHub Actions · Allure

## ▶️ Run the Project Locally

```bash
git clone https://github.com/sdet-kadarisuresh/playwright-typescript-ecommerce-automation.git
cd playwright-typescript-ecommerce-automation
npm install
npx playwright install
npx playwright test
```

To open the HTML report:

```bash
npx playwright show-report
```
